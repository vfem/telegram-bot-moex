# FEAT-02: Issuer Financial Statements & Balance Sheet (Итоговый баланс эмитента)

> **Feature ID:** `FEAT-02`  
> **Component:** `internal/provider/bfo`, `internal/domain`, `internal/service`, `internal/telegram`, `internal/store/memory`  
> **Priority:** P0 (Must Have)  
> **Target Cost:** $0.00 / month (Официальный API ФНС РФ bo.nalog.gov.ru)  

---

## 1. Описание и User Story

**Как** осмотрительный инвестор,  
**Я хочу** видеть ключевые финансовые показатели эмитента (итоговый баланс, собственный капитал, чистый долг, выручку и прибыль),  
**Чтобы** быстро оценить платежеспособность компании и уровень долговой нагрузки без необходимости скачивать и читать 100 страниц МСФО.

---

## 2. Архитектура и интеграция с ГИР БО (ФНС)

В РФ все юридические лица сдают обязательную годовую бухгалтерскую отчетность в **ГИР БО (Государственный информационный ресурс бухгалтерской отчетности)**, администрируемый Федеральной налоговой службой (ФНС).  
Ресурс предоставляет открытый и бесплатный REST API (`https://bo.nalog.gov.ru`).

- **Связка:**  
  1. Из MOEX ISS по ISIN получаем `emitent_inn` (ИНН эмитента, например `7708304947` для ПАО «ЕвроТранс»).
  2. Запросы в ГИР БО:
     - Поиск организации по ИНН:
       ```http
       GET https://bo.nalog.gov.ru/advanced-search/organizations/search?query={INN}
       ```
       Возвращает ID организации, краткое наименование и флаг `isCb` (кредитная организация ЦБ РФ).
     - Извлечение годовой бухгалтерской отчетности по найденному ID:
       ```http
       GET https://bo.nalog.gov.ru/nbo/organizations/{id}/bfo/
       ```
  3. Извлечение строк отчетности:
     - **Форма 1 (Бухгалтерский баланс):**
       - Строка `1600`: Итого активы (баланс).
       - Строка `1300`: Итого капитал и резервы (собственный капитал).
       - Строка `1410`: Долгосрочные заемные средства (кредиты и облигации > 1 года).
       - Строка `1510`: Краткосрочные заемные средства (кредиты и займы < 1 года).
       - Строка `1250`: Денежные средства и денежные эквиваленты (ДС).
     - **Форма 2 (Отчет о финансовых результатах):**
       - Строка `2110`: Выручка.
       - Строка `2400`: Чистая прибыль (убыток).
       - *(Строка `2330`: Проценты к уплате — зарезервирована для коэффициента покрытия процентов в FEAT-05).*
     - **Аудиторское заключение:**
       - Извлечение наименования аудиторской организации из `auditReport.name`.

## 3. Декомпозиция подзадач (Sub-tasks)

### `TASK-02-01`: Доменная модель `IssuerBalance`
- **Цель:** Представить ключевые показатели бухгалтерского баланса и отчета о прибылях/убытках со стабильными строковыми кодами рисков.
- **Файл:** `internal/domain/balance.go`
- **Коды риска долговой нагрузки (`DebtRiskLevel`):**
  - `RiskLow` (`"low"`): `🟢 Низкая нагрузка` (Долг/Капитал $\le 1.0$)
  - `RiskModerate` (`"moderate"`): `🟡 Умеренная нагрузка` (Долг/Капитал $1.0 .. 3.0$)
  - `RiskHigh` (`"high"`): `🔴 Высокая нагрузка` (Долг/Капитал $> 3.0$ или `Equity <= 0`)
  - `RiskSovereign` (`"sovereign"`): `⚪️ Суверенный эмитент` (ОФЗ Минфина РФ)
  - `RiskBank` (`"bank"`): `⚪️ Кредитная организация (ЦБ РФ)`
- **Форматирование денежных сумм (`FormatMoney`):**
  - $\ge 10^{12}$: `трлн ₽` (например, `1.0 трлн ₽`)
  - $\ge 10^9$: `млрд ₽` (например, `114.2 млрд ₽`)
  - $\ge 10^6$: `млн ₽` (например, `50.0 млн ₽`)
  - $< 10^6$: `тыс. ₽` (например, `500 тыс. ₽`)
- **Проверка контрольной суммы ИНН (`IsValidINN`):**
  - Официальный алгоритм ФНС для 10-значных ИНН (юрлица) и 12-значных ИНН (физлица/ИП) по весовым коэффициентам по модулю 11.

### `TASK-02-03`: Клиент ГИР БО (bo.nalog.gov.ru)
- **Цель:** Безопасный клиент к API ГИР БО с защитой от SSRF, контролем объема памяти и правильным сопоставлением ИНН.
- **Файл:** `internal/provider/bfo/client.go`
- **Защита от SSRF:** Валидация хостов и протоколов в `CheckRedirect` (запрет редиректов на приватные сети RFC 1918, `metadata.google.internal` и non-https схемы).
- **Защита от OOM:** Чтение ответов через `io.LimitReader(r, 4*1024*1024)`.
- **Строгое совпадение ИНН:** Если поисковая выдача не содержит точного совпадения по ИНН, возвращается `ErrOrganizationNotFound` (без случайных ложных ассоциаций).
- **Фильтрация годовых срезов:** Фильтрация по годовым отчетам (`Type == 12` или `0`) с выбором последней ревизии (`CorrectionVersion`).

---

### `TASK-02-04`: Расчет финансовой устойчивости и коэффициентов
- **Цель:** Вычисление ключевых коэффициентов долговой нагрузки:
  - `NetDebt = (LongTermDebt + ShortTermDebt) - CashEquivalents`
  - `DebtToEquity = NetDebt / Equity`
- **Особые случаи:**
  - `Equity <= 0` (отрицательный или нулевой капитал) $\to$ `🔴 Высокая нагрузка (отриц. капитал)`.
  - `NetDebt < 0` (денежные средства превышают совокупный долг) $\to$ в Telegram отображается как `Чистая ден. позиция (🟢 Низкая нагрузка)`.

---

### `TASK-02-05`: Кэширование, дедупликация и защита от спама
- **Цель:** Исключить повторные запросы к серверу ФНС при частых запросах пользователями.
- **Файлы:** `internal/store/memory/financials_cache.go`, `internal/service/financials_service.go`
- **Параметры:**
  - TTL положительного кэша: **30 дней**.
  - TTL негативного кэша: **2 часа** (`SetNotFound` для несуществующих организаций или отсутствующих отчетов).
  - Copy-on-Write: Защита от мутаций закэшированных структур в памяти.
  - Атомарная ленивая эвикция под `sync.RWMutex`.
  - Ограничение емкости: 5 000 записей (LRU-style prune 20% старейших при переполнении).
  - Singleflight: Дедупликация одновременных запросов по одному ИНН (`singleflightGroup`) предотвращает dog-pile запросы к ФНС.
  - *Примечание:* Постоянный Firestore-адаптер для бухотчетности отложен до Этапа 2.5 с целью гарантированного сохранения квот Free Tier ($0.00/мес).

---

### `TASK-02-06`: Форматтер выжимки баланса в Telegram и маршрутизация команд
- **Цель:** Сформировать лаконичное сообщение с безопасным MarkdownV2 экранированием.
- **Файлы:** `internal/telegram/formatters.go`, `internal/telegram/bot.go`
- **Команды:** `/balance <ISIN|ИНН|Тикер>` и короткий алиас `/bal <query>`.
- **Токенизация команд:** Корректное выделение команд с суффиксом `@bot_name` без ложного срабатывания на префиксы (`/ballast`).
- **Раздельные сообщения об ошибках:**
  - Неверный формат идентификатора (`service.ErrInvalidIdentifier`)
  - Неверная контрольная сумма ИНН (`service.ErrInvalidINNChecksum`)
  - Эмитент не найден в ГИР БО (`service.ErrIssuerNotFound`)
  - Облигация не найдена (`service.ErrBondNotFound`)

## 4. Результаты реализации и технические заметки

### Статус: ✅ ЗАВЕРШЕНО (Все замечания код-ревью закрыты с BDD)

1. **Реализованные компоненты:**
   - `internal/domain/balance.go`: доменная модель `IssuerBalance`, классификация уровней риска `DebtRiskLevel` со стабильными кодами (`low`, `moderate`, `high`, `bank`, `sovereign`, `unknown`), метод `.Label()`, валидатор контрольной суммы ИНН `IsValidINN(inn)` и масштабирование денежных сумм `FormatMoney()` до триллионов.
   - `internal/provider/bfo/client.go`: интеграция с открытым API ГИР БО ФНС (`bo.nalog.gov.ru`) со строгим сопоставлением ИНН (`ErrOrganizationNotFound`), фильтрацией годовых срезов `type = 12` и выбором последней версии коррекции.
   - `internal/store/memory/financials_cache.go`: потокобезопасный in-memory кэш с TTL 30 дней, copy-on-write, негативным кэшированием (2 часа) и ограничением емкости до 5 000 записей.
   - `internal/service/financials_service.go`: сервисный слой с защитой `singleflightGroup`, негативным кэшированием, строгой валидацией входных аргументов по regex-белым спискам и проверкой контрольной суммы ИНН. Точное разграничение федерального суверенного долга (ИНН `7710168360`) от региональных/муниципальных займов.
   - `internal/telegram/formatters.go`: MarkdownV2 форматтер `FormatIssuerBalance` с отображением чистой денежной позиции для кэш-богатых компаний и экранированием спецсимволов.
   - `internal/telegram/bot.go`: обработчик команд `/balance` и `/bal`, токенизация команд с поддержкой синтаксиса `@bot` и экранирование скобок в `/help`.
   - `features/issuer_balance_sheet.feature` & `tests/bdd/balance_steps.go`: 12 сквозных BDD-сценариев.
   - `tests/integration/live_probe_test.go`: живой интеграционный тест `TestLiveBFOBalance` с проверкой на ПАО «Газпром» и ОФЗ Минфина РФ.

2. **Безопасность и Cloud Run Guardrails:**
   - **Anti-SSRF:** `http.Client.CheckRedirect` блокирует переход на приватные подсети (RFC 1918), link-local (`169.254.169.254`, `metadata.google.internal`) и non-https схемы.
   - **Лимит памяти (OOM protection):** парсинг ответов внешних API защищен `io.LimitReader` (максимум 4 МБ).
   - **Защита от инъекций:** строгий regex-whitelisting параметров команд `/balance <arg>`.
   - **Защита от upstream dog-piling:** валидация контрольной суммы ИНН, дедупликация singleflight и негативное кэширование на 2 часа исключают спам в сторону ФНС.
   - **Нулевая стоимость:** API ГИР БО полностью публичный и бесплатный, без необходимости API-ключей ($0.00/мес).
