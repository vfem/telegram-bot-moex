# FEAT-05: Decision Support Memo & Interactive Telegram UX ("Единое окно")

> **Feature ID:** `FEAT-05`  
> **Component:** `internal/service`, `internal/telegram`  
> **Priority:** P0 (Must Have - Ключевая цель фидбека)  
> **Dependencies:** `FEAT-01`, `FEAT-02`, `FEAT-03`, `FEAT-04`  

---

## 1. Описание и User Story

**Как** инвестор, выбирающий ценные бумаги в Telegram-боте,  
**Я хочу** в один клик получить консолидированную карточку инструмента («Инвест-паспорт» / Decision Memo) с экспресс-светофором рисков (🟢/🟡/🔴) и переключаться между разделами (Рынок, Баланс, События, Выплаты) прямо под сообщением,  
**Чтобы** принять осознанное решение о сделке в одном окне за 10 секунд без ручного сбора данных по разным сайтам.

---

## 2. Архитектура и компоновка данных

`FEAT-05` является фасадом и координатором данных всех нижележащих сервисов:
- `BondService` (спецификация выпуска и график выплат)
- `MarketDataService` (котировки, спред, объемы)
- `FinancialsService` (баланс, капитал, долг)
- `FactsService` (лента существенных фактов)
- `RatingsService` (кредитный рейтинг и аудит)


## 3. Декомпозиция подзадач (Sub-tasks)

### `TASK-05-01`: Композитный сервис `DecisionMemoService`
- **Файл:** `internal/service/decision_memo_service.go`
- **Модель:**
  ```go
  package domain

  type DecisionMemo struct {
      Bond          *Bond
      Market        *MarketData
      Balance       *IssuerBalance
      RecentFacts   []MaterialFact
      Rating        *CreditRating
      Audit         *AuditInfo
      RiskScore     RiskScore
      UpcomingPays  []Payment
  }

  type RiskScore struct {
      TrafficLight  string   // "🟢 Низкий", "🟡 Умеренный", "🔴 Высокий (ВДО)"
      PositiveFlags []string // "Рейтинг инвестиционного уровня", "Чистый аудит"
      WarningFlags  []string // "Высокая долговая нагрузка", "Низкая ликвидность"
  }
  ```
- **Параллельная загрузка:** Использование `errgroup.Group` для одновременного параллельного запроса данных ко всем провайдерам (целевое время ответа: < 500 мс).

---

### `TASK-05-02`: Алгоритм экспресс-оценки «Светофор рисков» (Traffic Light)
- **Цель:** Быстро выделить ключевые риски и плюсы бумаги по чек-листу:
  1. **Кредитный рейтинг:**
     - `>= ruA / A(RU)` -> 🟢 (+1)
     - `ruBBB / BBB(RU)` -> 🟡 (0)
     - `< ruBBB` или без рейтинга -> 🔴 (-2)
  2. **Долговая нагрузка (Долг/Капитал):**
     - `< 1.0` -> 🟢 (+1)
     - `1.0 ... 2.5` -> 🟡 (0)
     - `> 2.5` или отрицательный капитал -> 🔴 (-2)
  3. **Аудиторское заключение:**
     - Безоговорочно положительное -> 🟢 (+1)
     - С оговорками / отказ -> 🔴 (-3)
  4. **Ликвидность:**
     - Оборот > 5 млн ₽/день -> 🟢 (+1)
     - Оборот < 500 тыс. ₽/день -> 🔴 (-1)
- **Итоговый вердикт:**
  - 🟢 **Низкий риск:** Надежный эмитент, подходит консервативным инвесторам.
  - 🟡 **Умеренный риск:** Требует периодического контроля оферт и отчетности.
  - 🔴 **Повышенный риск (ВДО / Спекулятивно):** Высокая доходность сопряжена с риском потерь.

### `TASK-05-03`: Telegram Inline-клавиатура и навигация
- **Файл:** `internal/telegram/keyboards.go`
- **Callback Data Scheme:**
  `memo:{isin}:{tab}`
  Где `{tab}` может принимать значения:
  - `overview` — Главная сводка и светофор
  - `market` — Стакан, спред, объемы
  - `balance` — Итоговый баланс и выручка
  - `facts` — Свежие существенные факты
  - `schedule` — График ближайших выплат

---

### `TASK-05-04`: Обработчик Callback Query (`editMessageText`)
- **Файл:** `internal/telegram/bot.go`
- **Логика:**
  - При клике на кнопку бот не отправляет новое сообщение в чат, а обновляет текст существующего через `editMessageText`.
  - Активная вкладка подсвечивается (например, `[ • Баланс • ]`).
  - Обеспечивается мгновенный переход между разделами без задержек.

---

### `TASK-05-05`: Команда `/memo <ISIN>` и кнопка в `/bond`
- **Цель:** Бесшовный доступ к аналитической карточке.
- **Интеграция:**
  - Прямой вызов: `/memo SU26238RMFS4` или `/memo ЕвроТранс`.
  - Вызов из существующей карточки: под `/bond <ISIN>` добавляется инлайн-кнопка:  
    `[ 📑 Инвест-паспорт и анализ ]`.
