## 1. Введение и пользовательский контекст (User Need)

### Исходный фидбек:
> *«По отдельности можно все достать в интернете. Я бы хотел, чтобы всё можно было посмотреть в одном месте. Отчётность, но не всю, а только итоговый баланс-можно взять с сайта эмитента. Сообщения о существенных фактах тоже можно найти на сайте. Котировки, объемы можно найти в приложении брокера. Аналитику на сайтах брокеров, аналитических и аудиторских контор.*  
> *Все это будет входной информацией для анализа до принятия решения о действиях с бумагами.»*

### Проблема:
Инвестор тратит значительное время на проверку инструмента перед покупкой/продажей, переключаясь между 4–5 независимыми ресурсами:
1. Терминал / приложение брокера — котировки, стакан, текущий объем торгов, спред.
2. Сайт раскрытия информации (e-disclosure) / сайт эмитента — годовые/квартальные отчеты, поиск итогового баланса.
3. Лента существенных фактов — проверка на дефолты, оферты, созывы ВОСА/ГОСА, судебные иски.
4. Сайты рейтинговых агентств (АКРА, Эксперт РА и др.) и брокерская аналитика — кредитные рейтинги и аудиторские заключения.

### Цель решения:
Создать внутри Telegram-бота **«Единое окно принятия решений» (Decision Support Memo / Инвест-паспорт бумаги)**.  
Бот должен агрегировать и компактно представлять ключевые метрики в одном интерактивном сообщении с вкладками (Telegram Inline Keyboard), отвечая философии проекта: **100% бесплатные/публичные источники данных, нулевая стоимость инфраструктуры (\$0/мес)**.

## 3. Источники данных и архитектура интеграции

| Блок данных | Источник данных | Протокол / Формат | Авторизация / Стоимость | Стратегия кэширования |
|---|---|---|---|---|
| **Котировки и объемы** | **MOEX ISS** (`iss/engines/stock/markets/bonds/securities/{SECID}`) | REST / JSON | Публичный (без ключа), \$0 | 2 мин (в торговые часы 09:50–23:50 МСК) / 60 мин вне сессии |
| **Итоговый баланс** | **ГИР БО (`bo.nalog.gov.ru` API)** — Госинформресурс бухотчетности ФНС РФ | REST / JSON (по ИНН эмитента) | Официальный публичный API ФНС, \$0 | 30 дней (положительный кэш) / 2 часа (негативный кэш) |
| **Существенные факты** | **e-disclosure.ru (Интерфакс-ЦРКИ)** / Новости MOEX | RSS / REST / HTML-парсер | Публичные ленты, \$0 | 30–60 минут |
| **Кредитные рейтинги** | **Реестры агентств (АКРА, RAEX)** + Метаданные листинга MOEX | REST / JSON | Публичные данные, \$0 | 7 дней |

> [!TIP]
> **Связующий идентификатор:** Связующим звеном между рыночными данными (ISIN/тикер) и корпоративными данными (баланс, факты, аудит) является **ИНН эмитента (`emitent_inn`)**. Он уже доступен в ответе `description` запроса MOEX ISS API.

## 6. Метрики успеха (Acceptance Criteria)

1. **Скорость ответа:** Полный профиль формируется менее чем за 800 мс (благодаря кэшированию фундаментала и параллельным запросам к MOEX ISS).
2. **Нулевая стоимость:** Все используемые API не требуют платных подписок и работают в рамках GCP Cloud Run Free Tier.
3. **Решение пользователя:** Инвестор получает исчерпывающую информацию для решения «брать/не брать» за 1 клик, не покидая Telegram.
